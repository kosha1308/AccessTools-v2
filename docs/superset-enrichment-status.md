# Новые данные Superset для сводки

Учтена редакция ТЗ v0.13 от16.10.2026, изменённая10:34UTC. Сравнение с полученной
предыдущей ревизией описано в tz-update-2026-10-16.md; локальный рабочий текст ТЗ
обновлён, прежний снимок сохранён отдельно. Изменения относятся к наполнению сводки
и приёмке выпуска; существующее чтение формы не отменяется.

Добавлен read-only адаптер уже связанной и отфильтрованной вкладки Superset.
Он собирает hostname, сервис, полное имя ИС и новые поля:

- «СКУФ ГРУППА ТП»;
- «КОМАНДА ПОДДЕРЖКИ».

Сведения берутся из обычных исходных колонок всех видимых относящихся строк.
Лишние пробелы в заголовках не мешают поиску. Повторы значений удаляются без
учёта регистра, несколько значений выводятся через перенос строки. Hostname
остаётся пустым при неоднозначности. Связи через номера точные:1 не совпадает с10,
повтор номера в одной source-строке не увеличивает счётчик. Один source-ряд может
наполнять несколько строк сводки. Запрошенные номера без совпадений сохраняются.

Исходные значения, формулы, фильтр и скрытые строки не меняются. ERROR относящейся
видимой ячейки, повреждённая связь или превышение лимита не дают частичной сводки.
Внутренние ошибки скрытых/не относящихся к запросу данных не подменяют результат.
Результат immutable и работает после закрытия источника, кеша по имени книги нет.

Компиляция VBA и полный набор в Excel: **9845 PASS / 0 FAIL**, отчёт
`artifacts/excel-da4bf09d1a7249998cc068d00a735f61`. Static7/7, Excel gate9/9,
catalogmatch. Независимое read-only ревью не нашло дефектов, требующих исправления.
Тесты используют синтетические данные, включая AutoFilter/manual Hidden, multiline,
дубли, ошибки ячеек, неверные номера, schema/размер/объём работы и повторное чтение.
Практическая производительность при одновременных максимумах всех лимитов отдельно
не измерена; адаптер ограничен10000 физическими строками/1000000 ячейками.

Это **не полный пользовательский результат**: построение IP-связей, hostname
refinement, актуальность файла, base поля/Rulebook, writer книги ATVIEW_SUPERSET,
production-профиль/fingerprint и XLAM ещё предстоят. Старая проверка85/0/0 из ТЗ
не выдаётся за приёмку v2. Перед выпуском обязательна реальная заявка со всеми
пятью информационными полями Superset и общим координаторским сценарием.
