# Одиночные поля: проверки и русский отчёт

Работают шесть локальных проверок: обязательные поля инициатора, синтаксис
почты, тип заявки, ИЭП, срок действия и верхнее обоснование. Отчёт собирает
независимые проблемы за один запуск: причина, важность, поле и адрес ячейки.
Коллекции и отдельные записи отчёта неизменяемы, исходная книга не изменяется.

Обязательны ФИО, подразделение, должность и почта. Контакт остаётся необязательным.
Пустая почта не порождает повторную ошибку синтаксиса. Обоснование даёт WARNING.
При отзыве срок не проверяется; при неизвестном типе проверка срока пропускается
до исправления типа. При предоставлении допустим бессрочный срок или дата,
не предшествующая явной дате запуска. Часы и настройки локали компьютера не читаются.

Для совместимости добавлен явный режим даты DMY_TEXT: обычная ISO-дата целиком
либо дата в словах, например «до 30.12.2026». Если дат несколько, используется
последняя корректная. Сохранены системы дат Excel 1900/1904 и прежние строгие режимы.
Числовой текст не становится числовой датой; неверные цифровые границы не спасаются
частичным разбором. Scanner ограничен 65536 символами.

Семантика сверена только для чтения с действующей версией AccessTools,
commit d9aa9b88f9193c0d2935d99c5cc8ecca3865687c. Приватный код и данные не копируются.
Синтаксис почты сохраняет прежний ASCII-контракт, без дополнительного RFC-ужесточения.

Scope отчёта — **NETWORK_DOCUMENT**, а не полный NETWORK_ACCESS. Отсутствие ошибок
в этих шести проверках не означает успешную проверку таблиц, разрешений инициатора,
Rulebook, Superset или сводки координатора. Excel-лист отчёта/UI ещё не подключён.
Это не пользовательский выпуск 2.0.
