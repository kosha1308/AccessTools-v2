# Поиск адресов заявки в Superset

Продолжение PR20. `ATNetworkRegistryPlanner.Run(request, compiledIndex, optionalBudget)`
собирает числовые адреса обеих таблиц, возвращает frozen `ATNetworkRegistryResult`
с Entries, Report и SourceIssues. `ATNetworkAccessChecks.ApplyRegistry` добавляет
NET.IP_REGISTRY к готовому запуску14 проверок, сохраняя прежние исходы и сообщения.

Одна запись соответствует уникальному математическому IP/сети/диапазону. IP и /32,
эквивалентные маски/CIDR объединяются; все ссылки на исходные ячейки сохраняются.
ID присваивается по первому появлению: верхняя таблица source/destination, затем
нижняя address. Сети не разворачиваются в отдельные IP. Текстовые группы
не раскрываются; числовые адреса нижней таблицы участвуют независимо от групп.
Корректные отдельные объявления рядом с неверным адресом сохраняются с явным
предупреждением; compact-prefix после ошибки или группы сбрасывается.

Hostname нижней строки уточняет только singleton IP с тем же математическим
ключом: при точном совпадении сохраняются все подходящие строки, иначе остаются
все IP-совпадения. Регистр, включая кириллицу, и завершающая точка игнорируются.
Для сетей hostname не сужает поиск. Ошибка hostname источника или любой нижней
строки данного IP запрещает сужение, чтобы не терять другие сервисы.

FOUND / NOT_FOUND / UNCONFIRMED сохраняются и для адресов без совпадений.
Неполный или отсутствующий источник не подтверждает отсутствие IP. Проблемы
источника доступны отдельно. NOT_FOUND использует опубликованный ключ Rulebook
`NET.IP_REGISTRY|WARNING|Проверка IP`: предупреждение, не ошибка пользователя,
канал Superset/координатора. Незавершённый результат требует ручной проверки;
настроенное повышение severity до ERROR имеет приоритет. Ошибка нового этапа
или оформления сообщений не стирает предыдущие14 проверок.

Общий бюджет200000 шагов, до10000 entries,100000 исходных связей и990 проблем.
При структурной ошибке/исчерпании бюджета выдаётся BLOCKED с пустыми entries,
без частичного успешного результата. Внешний бюджет при передаче соблюдается.

## Проверка

Компиляция VBA и полный набор тестов выполняются в отдельном Excel. На текущем
Windows-хосте используется явный TimeoutSeconds90; стандартный тайм-аут60 и
производственные бюджеты не менялись. Добавлены сценарии групп/нижних IP,
дедупликации/ссылок, масок, hostname fallback/ошибок, неполного источника,
immutability, лимитов, маршрутизации и сохранения14 предыдущих исходов.
Независимое ревью выявило потерю совпадений при ошибке hostname повторной строки;
регрессионный тест воспроизвёл дефект, флаг непроверенного имени запрещает сужение.

На предоставленных трёх книгах ReadOnly:25 проверок прошли; каталог, инициаторы,
общие правила, RAW Superset, индекс, заявка,15 исходов и отдельный Excel-отчёт
совместимы. SHA256 всех трёх файлов до/после совпали. Пустой Superset подтверждает
совместимость структуры; совпадения с данными проверены синтетическими тестами.
