# Этап 2B.1 — IP и порты для проверок связностей

Техническое решение принимает исполнитель: пользователь явно делегировал устройство
ядра и согласования технических деталей. Сценарий использования уточнён по ТЗ v0.13:
связности верхней технической таблицы, адреса нижней таблицы, результаты с ячейками.

## До первого использования

Проверяемая первая версия требует последовательно: (1) IP/порты; (2) строки таблиц
и чтение эталонного NETWORK_ACCESS без изменения заявки; (3) результаты и переход
к ячейке; (4) готовый Excel-пакет, smoke и сравнение с действующими проверками.
Завершение текущего шага не является готовностью всей версии 2.0. Исполнитель
сообщает пользователю о готовности только после проверки поставляемого файла.

## Выбор

Единый чистый VBA interval layer выбран вместо перечисления всех IP/портов или
regex extraction: диапазоны огромны, а невалидный хвост нельзя потерять. Старый
AccessTools прочитан только как oracle; зависимости/копии private-кода в публичный
v2 не добавляются. Примеры тестов синтетические, без рабочих данных/справочников.

ATIntervalRange неизменяем; ATIntervalSet строит отсортированное объединение
непересекающихся/несмежных диапазонов, затем замораживается. Endpoints — точные
целые Double: IPv4 0..4294967295, PORT 0..65535. Никакого signed Long для IPv4.
Пересечение и полное покрытие проходят по нормализованным интервалам; все циклы
расходуют ATEvalBudget. Ограничение числа интервалов — MaxListItems, текста —
MaxTextLength; expansion wildcard расходует MaxSteps. Лимит даёт ERROR, не FALSE.

## Ввод и семантика

IPv4: четыре ASCII десятичных октета по 1–3 цифры, 0..255. Ведущие нули
канонизируются. CIDR /0..32 (1–2 цифры) нормализуется в network bounds для coverage,
при этом исходный канонический base IP/prefix сохраняется как декларация.
Поддержаны полные диапазоны, compact endpoint, compact comma lists и x по целому
октету (регистр не важен). Диапазон IPv4 с обратными endpoints упорядочивается,
как legacy interval layer; диапазон портов с обратными endpoints невалиден.
Неполные/длинные октеты, текст, IPv6 и частичный x не угадываются.

Разделители IP: запятая, ;, |, CR/LF, tab, пробелы. Compact continuation использует
последний IPv4 prefix до следующего полного элемента; голый номер без prefix invalid.
Порты: числа и диапазоны, те же разделители плюс / и backslash. Unicode range dashes
нормализуются только внутри domain parser, а не свободного текста. Пробелы вокруг
тире допустимы. Пустая строка даёт EMPTY; любой неверный token делает весь результат
INVALID с диагностикой. Никакие валидные куски не скрывают неверные.

Kernel допускает порт 0 по принятому unsigned-контракту; NETWORK_ACCESS adapter
сможет отдельно запретить его как бизнес-значение. NoPolicyAction не выбирается.

RuntimeValue получает неизменяемый domain payload и отдельные declaration keys;
Scalar getter не возвращает domain как строку. Clone безопасно разделяет только
замороженные интервалы. ValidateBudget проверяет payload до копирования.
IP принимает один plain IPv4; IP_EXPRESSION — составное выражение; PORT — одно число;
PORT_SET — множество. Нормализация не добавляет неявную TEXT→IP конверсию в DSL.
NUMBER/LIST<NUMBER>→PORT_SET выполняется по сохранённому normalizer binding с
проверкой каждого значения в Runtime. Результат поля обязан совпадать с compiled type.

ANY/OVERLAPS/INTERSECTS — непустое пересечение; NONE — пустое;
COVER/CONTAINED_BY/IN — A subset R; CONTAINS — R subset A; EXACT и '=' —
равенство покрытия. NOT остаётся обычной логикой. Порядок/дубликаты безразличны.
Отдельный helper сравнения деклараций для будущего TOP↔LOWER сохраняет строгость
CIDR: plain IP != /32, разные base IP одной сети !=. Ordinary IP/ranges/compact
forms сравниваются по фактическому покрытию. CIDR keys и non-CIDR coverage
сравниваются независимо. Invalid не считается равным invalid и не превращается в PASS.

## Приёмка и граница

Тесты: endpoints /0,/32, signed boundary, partial-vs-full coverage, gaps, duplicates,
compact/dashes, malformed tails, masks with internal x, PORT0/65535/out-of-range,
конверсии вычисленных чисел/списков, strict CIDR declarations и limits. Добавить
небольшой исчерпывающий oracle на bool-массивах для interval algebra. Существующие
1264 assertions сохраняются. Compile Excel, tooling, independent review, чистая
копия и CI обязательны. Строки/источники/GUI/policy и реальная заявка — следующий шаг.
