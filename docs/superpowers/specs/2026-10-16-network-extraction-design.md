# Чтение таблиц заявки Excel

Цель — передать верхнюю и нижнюю таблицы в существующий immutable row runtime,
не изменяя книгу пользователя. Полный первый выпуск по-прежнему требует проверок
NETWORK_ACCESS, Superset и сводки координатора. Этот этап не является выпуском.

## Решение

Выбран общий читатель по описанию колонок. Специализированный обход с названиями
NETWORK_ACCESS внутри ядра нарушил бы границу шаблона; полная Admin-среда сейчас
избыточна. Описание передаётся вызывающим адаптером, без зависимости от старого репозитория.

ATExcelTableSpec задаёт TableId, прямоугольник поиска заголовка и колонки:
FieldId, точный HeaderText, Usage=INHERITED/DIRECT/NONE. Поиск принимает ровно
одну полную строку обязательных заголовков; пропуск, дубликат или неоднозначность
дают ошибку. Регистр и визуальные пробелы заголовков нормализуются. Перестановка
колонок допустима. Объединённый заголовок задаёт левую колонку и нижнюю границу.
Это структурный locator, а не полный строгий fingerprint эталона.

ATExcelTableLayout хранит найденную структуру и привязку к листу. Reader возвращает
ATEvalResult с COLLECTION<ROW<TableId>>. FieldId задаётся снаружи; все поля здесь
имеют тип TEXT и сохраняют исходный текст целиком. Доменная нормализация остаётся
отдельным шагом: недопустимо извлекать только корректный IP из испорченной строки.
Числа Value2 переводятся в invariant текст, ошибки Excel — в ERROR поля.
Визуально пустые значения становятся EMPTY. RowId — физический номер строки;
CellRef содержит экранированное имя листа и адрес исходного merged anchor.

## Строки и границы

INHERITED делает строку используемой по значению объединённого якоря;
DIRECT — только если значение физически введено на этой строке;
NONE не создаёт строку, но значение наследуется в уже используемой строке.
Для верхних четырёх ключевых колонок используется INHERITED, для обоснования NONE.
Для нижней таблицы используется DIRECT: отдельные system/role записи остаются
проверяемыми, но наследуемые вспомогательные значения не создают spacer-строки.
Blank = пробел/NBSP/tab/CR/LF/zero-width/BOM и формула с результатом пустой строки.
В непустом исходном тексте переносы и символы сохраняются.

Верхний lastDataRow задаётся вызывающим адаптером как начало нижнего заголовка - 1.
Нижний lastDataRow определяется по значениям только рабочих колонок, не UsedRange.
Find имеет явно заданные параметры; максимум 10000 кандидатов на колонку.
Читатель получает Value2 одним блоком, максимум 10000 физических строк/1000000 ячеек,
и хранит метаданные объединённых областей на текущий вызов. Объединение, выходящее
за границу таблицы/прямоугольника, отвергается. Нет глобального кеша по имени книги.
Превышение лимита — явная ошибка, без частичного результата. После ошибки читатель
можно использовать повторно. Результат не содержит Range/Worksheet и переживает
изменение/закрытие источника. Полностью пустая таблица допустима.

## Приёмка

Реальные временные листы в тестовом Excel: merged обоснование и пустые строки,
частично merged ключи, нижние merged system/role, отдельное auxiliary значение,
формула пустоты, ошибочная ячейка, multiline/invalid IP, перестановка/merged headers,
неоднозначный/неполный заголовок, форматирование последней строки листа, лимиты,
неправильный лист/пересечение границы, immutable snapshot и выполнение DSL по нему.
Исходные значения, формулы, объединения и оформление не меняются.

Профиль публикации, одиночные поля, fingerprint, полный rulebook, Superset и UI
остаются следующими шагами; описание колонок пока является программным API.
Технические решения делегированы пользователем; выполняем без нового согласования ядра.
