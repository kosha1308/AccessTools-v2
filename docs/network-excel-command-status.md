# Команда Excel для связанностей

Добавлены две русские команды:

1. `ПроверитьСвязанности` — захватывает текущий лист заявки, проверяет профиль,
   предлагает выбрать XLSX книги правил и выгрузки Superset, затем вызывает
   существующий контроллер. Результат — открытые отчёт и сводка координатора.
2. `СохранитьРезультатыСвязанностей` — сохраняет копии обеих книг последнего
   завершённого запуска. В Excel с загруженными модулями команды доступны через
   Alt+F8. Готовая надстройка для пользователя ещё не собрана.

После обработки команда сообщает отдельно о завершении запуска и прохождении
проверок. Замечания, пропуски и неполные проверки требуют изучения отчёта.
Техническая ошибка не выдаётся за успешную проверку заявки.

## Сохранение и отмена

Выбирается существующая папка. Внутри создаётся новая подпапка
`AccessTools_YYYYMMDD_HHMMSS_NNN` с файлами `Отчёт-проверок.xlsx` и
`Сводка-координатора.xlsx`. Существующие результаты не перезаписываются.
Экспорт сохраняет копии; имена, расположение и несохранённые изменения открытых
результатов не меняются. Пользовательские книги не закрываются.

Отказ от сохранения и отмена выбора папки оставляют результаты открытыми.
Повторное сохранение доступно отдельной командой. При новом запуске ссылка
на прошлый результат сбрасывается до выбора файлов. Если новый запуск отменён
или завершился ошибкой, команда сохранения не выдаст старые результаты за новые.
Предыдущие открытые книги при этом остаются доступны пользователю.

Если экспорт прерван, удаляются только два файла из созданной этим экспортом
папки. Папка удаляется только пустой; посторонние вложения не удаляются.
Ошибка очистки может оставить частичные файлы: сообщение не заявляет об успехе.
Открытые результаты сохраняются для повторной попытки.

## Дата и настройки

Дата запуска фиксируется по местному времени Windows с текущим смещением UTC.
Используется [GetTimeZoneInformation](https://learn.microsoft.com/en-us/windows/win32/api/timezoneapi/nf-timezoneapi-gettimezoneinformation),
учитывается текущий режим стандартного/летнего времени. Это смещение данного
запуска, а не идентификатор часового пояса для будущих дат.
Восстанавливаются строка состояния, обновление экрана и обработка событий Excel.
При старте Excel источники автоматически не загружаются. Настройки безопасности
и реестр не меняются.

## Проверка и границы этапа

Проверены в настоящем Excel читаемые копии обеих книг, повторный экспорт,
сохранность предыдущей папки, исходные открытые книги и настройки событий,
отказ при отсутствующей папке/совпадающих книгах, запрет сохранения до запуска,
после сбоя и после сброса, полный путь от искусственной заявки до сохранения.
Завершённые 16 проверок и контроллер не изменены.

Компиляция VBA PASS; полный набор: 11303 PASS / 0 FAIL. Статические проверки
инструментария: 7/0. Независимая проверка кода не выявила блокирующих замечаний.
Тест сохранения прошёл цикл RED (11286/1) -> GREEN (11294/0); тест состояния
команды RED (10/3) -> GREEN (14/0), затем дополнен полным сценарием.

Диалоги выбора файлов, ответы на сообщения и отмена диалогов пока не пройдены
ручной приёмкой. Сбой диска между двумя записями проверен по коду очистки;
искусственный отказ файловой системы в тестах не моделировался. Это ещё не
пользовательский выпуск: нужны сборка XLAM, команда на ленте с учётом профиля,
приёмка интерфейса и установка в чистую папку. Отдельный сохранённый отчёт об
ошибке не входит в парный экспорт успешного запуска; его можно сохранить
обычной командой Excel.
