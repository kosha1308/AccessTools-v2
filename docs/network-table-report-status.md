# Проверки таблиц и отдельный отчёт Excel

Локальный запуск объединяет шесть проверок одиночных полей и три проверки
таблиц/протоколов. Пустые таблицы, обязательные поля, неверные числовые IP,
порты вне 1–65535 и ошибки Excel получают ERROR. Обоснование, название системы,
роль и дубликаты дают WARNING по соответствующим условиям.

Справочник протоколов передаётся явно. Проверяются все значения, разделённые
запятой, точкой с запятой, вертикальной чертой или ASCII-пробелами. Если справочника
нет, проверка явно пропущена и показано предупреждение. Невалидный справочник
останавливает результат, не оставляя частичных положительных исходов.

Текстовая группа IP требует ручной проверки: она не запрещается и не получает
автоматический PASS. Это консервативный режим, а не полный mixed-group classifier.
Точное сопоставление верхней/нижней таблиц, hostname по Rulebook, источники,
Superset и сводка координатора ещё не подключены. Scope — NETWORK_LOCAL,
а не полная проверка NETWORK_ACCESS. Пользовательский пакет ещё не готов.

## Видимый результат

Writer создаёт новую книгу с листами «Отчёт» и «Проверки». В ней русские
сообщения, счётчики, важность, адреса и переходы к исходным ячейкам. Источник
не меняется, автоматического сохранения поверх файлов нет. Пропуски и ограниченный
состав проверок указаны явно. Повторный запуск создаёт новую книгу.

Формат Text защищает сообщения от превращения в формулы. Ссылки строятся только
к переданному источнику и проверенному одиночному A1-адресу; чужие refs остаются
текстом. EnableEvents восстанавливается после успеха и исключений. Переход работает
для открытой несохранённой книги; для сохранённой используется её реальный путь.

## Проверка

Компиляция VBA и полный набор в настоящем Excel: **10430 PASS / 0 FAIL**.
Независимый обзор выявил склейку названий протоколов IP-парсером. Визуальная QA
выявила потерю начальной кавычки в отображении ref. Воспроизведение10426/4 →
отдельный protocol tokenizer и literal text escaping →10430/0. Неразрешённых
замечаний по корректности нет. Generic IP/port parser не изменялся.

Протестированы реальные переходы по hyperlink в собственную исходную книгу/A5,
запись formula-like текста, отказ чужих refs, повтор, события и сохранность источника.
Двухстраничная печатная визуализация вымышленного образца проверена: русские названия,
счётчики и адреса читаемы, поля не обрезаны. XLSX/PDF/PNG — только локальные QA-артефакты.

Оригинальный шаблон ReadOnly: `STATE=0|CHECKS=9|ERRORS=6|WARNINGS=2|LINKS=8` —
ожидаемые проблемы пустой формы и отсутствие каталога протоколов. SHA256 не изменился:
