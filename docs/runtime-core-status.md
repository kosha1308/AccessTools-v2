## Что добавлено в код

- Неизменяемые значения, отдельные состояния результата и данных, копирование
  входных значений и безопасный снимок контекста.
- Нормализация текста, чисел, Boolean и Gregorian date без региональных догадок.
- Выполнение типизированного AST: логика, арифметика, сравнения, общие правила
  с параметрами и значениями по умолчанию, списки и базовые функции.
- Ленивые AND/OR/COALESCE, явная передача ошибок/пропусков/ручной проверки.
- Ограничения шагов, глубины, строк, списков и объяснений; trace без данных полей.
- Диагностика неподдержанных операций до чтения их операндов.
- Исправления происхождения AST/предупреждений из первого этапа.

## Проверки и ревью

Написаны наборы runtime-model, normalize, evaluator, limits, primitive и acceptance.
Они включены в общий runner. Таблицы логических состояний и инспекторов данных,
параметры/defaults, повторные запуски, пустые списки, отложенные операции и лимиты
пока являются написанными тестами, а не доказанным поведением.

Статически проверены имена и уникальность 56 VBA-компонентов; tooling fixtures 7/7.
Независимое статическое ревью выявило четыре дефекта. Изменения для их устранения
внесены; подтверждение в Excel ожидается:

1. Переполнение trace сохраняет первичную ошибку и добавляет вторую диагностику.
2. Binding хранит IsDefault отдельно от SourceId: вложенный явный аргумент внутри
   default вычисляется в области вызывающей стороны.
3. Публичный конструктор DATE отвергает время, а не только нормализатор.
4. Контекстный снимок разделяет только неизменяемые внутренние результаты;
   размер/бюджет значения проверяются до копирования результата для evaluator.
