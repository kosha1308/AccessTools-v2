# Сопоставление адресов двух таблиц

В локальный отчёт добавлена десятая проверка: точное соответствие адресов
источника/назначения верхней таблицы адресам нижней. Лишние записи нижней
таблицы и отсутствующие в ней адреса отмечаются ошибками со ссылками на
конкретные исходные ячейки. Повторы одной записи не создают ложных расхождений.

IP, CIDR и диапазон остаются разными видами записей; равное покрытие адресов
не означает равенство заявленных записей. Некорректные числовые записи
сохраняются целиком, без превращения в частично распознанный IP.
Текстовые группы, маски, IPv6 и ошибки ячеек требуют ручной проверки:
автоматическое сопоставление явно пропускается без ложных расхождений.

Существующие проверки заполнения, протоколов, дат и механизм записи отчёта
не переделывались. Сохраняются ограничения ресурсов и отказ без частичных
положительных результатов при превышении лимита общего отчёта.
