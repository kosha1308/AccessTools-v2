# AccessTools 2.0 для сетевых связанностей

Готов комплект для пробного использования: **2.0.0-pilot.5**, AccessToolsv2.xlam.
Рабочий сценарий: проверка заявки, правила, поиск IP в Superset и сводка координатора.
Исходные проверки сохранены. Внешний вид ориентирован на привычную первую надстройку.

## Что работает

- Те же 16 проверок полей, обеих таблиц, инициаторов, IP-политик и технических правил.
- Поиск IP, применение правил Superset, сводка с сервисами и инструкциями координатору.
- Запоминание путей к книге правил и выгрузке между запусками Excel; данные читаются заново.
- Подсветка ошибок и собственные примечания в заявке, без изменения значений и автосохранения.
- Немодальное окно результатов: все ошибки пользователя, копирование, переход к ячейке,
  повторная проверка, очистка собственных отметок, открытие сводки и сохранение.
- Рабочая копия полной выгрузки Superset с отдельными вкладками сводки и найденных строк.
- Обычное сохранение одного Superset-с-результатами.xlsx в новой папке.
- Подробный отчёт только по кнопке «Диагностика», без автоматического открытия/экспорта.
- Разделы проверки и настройки шаблонов, список с поиском. Сейчас поддержан NETWORK_ACCESS.

## Комплект и первый запуск

Папка: outputs/AccessTools-v2-пилот-2.0.0-pilot.5.
Архив: AccessTools_Coordinator_2.0.0-pilot.5.zip.
Закройте Excel, распакуйте весь комплект в постоянную папку и подключите
AccessToolsv2.xlam. Обновляйте пакет целиком. Первая AccessTools.xlam может оставаться
подключённой. Русская инструкция — AccessTools/Прочитайте-сначала.txt.

Откройте Пример/Заявка-с-ошибками.xlsx. Выберите «Проверить заявку» →
«Сетевая связанность», при первом запуске укажите примеры правил и Superset.
Проверьте окно, переход к ячейке, повторную проверку, очистку и вставку скопированного
текста. Затем можно пробовать вашу заявку с вашими источниками через «Выбрать источники
связанностей». Перед запуском сохраните и закройте книгу правил и исходную выгрузку.

## Что проверено и что остаётся

VBE compile PASS; полный Excel11364 PASS / 0 FAIL. Загрузка готового XLAM15/0,
проверка извлечённого ZIP15/0, включая формы и повторное открытие сохранённого
рабочего Superset. Все исходные файлы примеров сохранили SHA256.

Вид окна, настоящие клики, повторный запуск из открытого окна и буфер обмена требуют
приёмки на вашем Excel. Реальные данные в автоматических тестах не использовались.
Это пилот координатора: профиль первой линии, полный Admin-конструктор шаблонов и
официальный выпуск для коллег остаются отдельными этапами. Конструктор не заменён
меню: сейчас через него доступны только существующие правила и источники.

fix/visible-request-annotations, draft PR31 поверх PR30; без слияния.
