# Ядро выполнения правил — этап 2A

Состояние на 2026-10-16: ядро реализовано и проверено в настольном Excel.
Полный набор: **1264 PASS / 0 FAIL**, включая существующие проверки компилятора.
Compile VBAProject PASS; справочник соответствует реестру. Статические tooling
fixtures 7/7, Excel gate integration 9/9. Чистая копия: evidence в progress.md.

## Реализованный объём

- Неизменяемые значения, отдельные состояния результата и данных, безопасный снимок контекста.
- Текст, конечные Double, Boolean и Gregorian date. Локаль INVARIANT; сравнение BINARY или ASCII_TRIM_CI, регистр только ASCII.
- Типизированный AST: логика, арифметика, сравнения, именованные выражения с параметрами/defaults, списки и базовые функции.
- Ленивые AND/OR/COALESCE, передача ERROR/SKIPPED/MANUAL_REVIEW без преобразования в Boolean.
- Ограничения шагов, глубины, строк, списков и trace без содержимого полей.
- Неподдержанные операции диагностируются до чтения операндов.
- Исправлено указание источника для предупреждений, BIND, source/lookup и synthetic LIST.

Это вычислительное ядро на явных in-memory контекстах, не весь Runtime продукта.
Run date передаётся явно с timezone identity; преобразование timestamp выполняет
будущий адаптер. Кэш и чтение системных настроек не добавлены.

## Выполненные проверки и исправления

Запущены model, normalize, evaluator, limits, primitive и acceptance suites.
Проверены логические состояния и инспекторы, параметры/defaults, повторные запуски,
пустые/некорректные списки, отложенные операции и ограничения.

Первый запуск после восстановления доступа выявил ошибки компиляции: недоступный
Private member другого экземпляра класса и зарезервированные имена local/scale.
Исправлены Friend boundary с проверкой заморозки и имена localFrame/factor.
Runner теперь сообщает расположение ошибки компиляции.

Затем 12 неуспешных assertions выявили приоритет PORT_SET conversion перед точной
LIST signature и отсутствие generic binding для таблицы с именем T. Type checker
сначала ищет совпадение без преобразований и всегда связывает generic T.
Результат после исправления: 1258 PASS / 0 FAIL.

Независимое статическое ревью проведено в два прохода. Исправлены:

1. Потеря первичной ошибки при переполнении trace.
2. Неверная область явного аргумента внутри default: binding хранит IsDefault отдельно.
3. Возможность передать время в DATE через публичный конструктор.
4. Копирование слишком большого списка до проверки лимита.
5. Успешное сравнение списка с непроверенным INVALID элементом после раннего совпадения.
6. Ненулевой underflow среднего до нуля без диагностики.

Последние два случая воспроизведены отдельными тестами: 3 FAIL до исправления,
**1264 PASS / 0 FAIL** после. Все первоначальные четыре regression cases также
выполнены в полном наборе. Важных замечаний без исправления не оставлено.
