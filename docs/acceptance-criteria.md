# Критерии приёмки AccessTools 2

Статусы: NOT STARTED / AUTOMATED PASS / EXCEL MANUAL PASS / REJECTED. Автоматические тесты и ручная приёмка независимы; `AUTOMATED PASS` не означает окончательное принятие.

| ID | Требование | Минимальная проверка | Статус |
| --- | --- | --- | --- |
| AC-01 | Создание шаблона без VBA | Новый Excel-образец → распознавание → сохранённый TemplateId | NOT STARTED |
| AC-02 | Поля/таблицы и адреса | Изменить диапазон в Admin; 2 правила используют новое место | NOT STARTED |
| AC-03 | Полное редактирование правил | Create/clone/edit/disable/archive/restore и повторный запуск | NOT STARTED |
| AC-04 | Условия и типы | AND/OR/NOT, таблицы, EMPTY/MISSING/INVALID/UNAVAILABLE | NOT STARTED |
| AC-05 | Общие источники | Две формы используют настраиваемый источник без нового VBA | NOT STARTED |
| AC-06 | Аннотации | Из UI задать ячейку, текст, цвет, примечание и роль | NOT STARTED |
| AC-07 | Сохранность Excel | Двойной запуск, сбой и очистка не стирают чужие примечания и стили | NOT STARTED |
| AC-08 | Публикация/откат | Черновик невидим Runtime; publish, rollback безопасны | NOT STARTED |
| AC-09 | Роли и lazy load | FIRST_LINE не читает Superset; COORDINATOR получает нужный результат | NOT STARTED |
| AC-10 | Независимый второй шаблон | Настройка без специализированного контроллера | NOT STARTED |
| AC-11 | Паритет v1 | Каждая реальная проверка сравнивается по логике, сообщениям и ячейкам | NOT STARTED |
| AC-12 | Полный Superset | Совпадают найденные/ненайденные адреса, обогащение и сводка | NOT STARTED |
| AC-13 | Надёжность Excel | Нет мигания; восстановлены Application flags при ошибках | NOT STARTED |
| AC-14 | Реальная сборка | XLAM compile + автоматические тесты + пользовательские клики | NOT STARTED |
| AC-15 | Сохранность старых проектов | AccessTools 1 и архив AccessTools 2 не изменены | NOT STARTED |
| AC-16 | Полный включительный IPv4-диапазон | .1–.10 содержит 10 адресов; внутренний deny .5 обнаружен; частичное .1–.8 не покрывает .9–.10; крайние точки в Superset не означают покрытия; большие диапазоны не разворачиваются в массив | NOT STARTED |

При выпуске отдельный протокол: версия Windows/Excel, источники и хеши тестовых книг, набор ручных сценариев, точные проходы/провалы и остаточные риски.

Подробности: ТЗ v0.15, раздел 10.
