# Структурная проверка шаблона

Подключён профиль NETWORK_ACCESS для предоставленного пользователем пустого
[эталона формы v3.0](https://drive.google.com/file/d/1An-gcbJkeZl0u4KsvmIAnUgSA4b5jiF9/view)
из Drive work/Шаблоны заявок. В репозитории находится только описание структуры
и синтетические тесты; оригинальный XLSX не публикуется.

Профиль проверяет лист, title/version, обязательные служебные метки, геометрию
объединений, полные группы заголовков двух таблиц и взаимное расположение.
Значения инициатора, IP, C7/C8/C12, обоснования и списки выбора не участвуют
в fingerprint. Нижний заголовок может смещаться после добавления технических строк.
Отдельное слово из пользовательских данных не принимается за целую таблицу.
Текущий эталон не защищён, часть меток unlocked: профиль не меняет эти свойства
и не вводит требования, которым предоставленная форма не соответствует.

Общий ATTemplateProfile sealed и не меняется после проверки metadata. Поддерживает
опциональные Locked/ProtectContents, ограниченные области и относительные offsets.
Любое несовпадение даёт один отказ «Используйте актуальный шаблон заявки.»;
неверная конфигурация/ошибка чтения также не разрешают запуск.
ATTemplateTableGate сначала проверяет профиль, затем заново находит таблицу
по её описанию и только после этого читает данные. Старый layout не принимается.
Это ещё не весь dispatcher приложения: одиночные поля и общий набор checks предстоит
объединить с этим входом; актуальную lastDataRow задаёт вызывающий pipeline.

Компиляция VBA и полный набор: **9889 PASS / 0 FAIL**, catalogmatch, отчёт
`artifacts/excel-d04e7e2da1f34a0cba720e38d134f288`. Static7/7, Excel gate9/9.
На настоящем XLSX, открытом ReadOnly в отдельном supervised Excel:
`True|TEMPLATE_MATCH|NETWORK_ACCESS@3.0-profile1`.
SHA256 до/после совпадает:
`21684A4A985FD2057193B557E9D09C817C0899CE09DF7C697EF45025BC6714A7`.

Независимое ревью выявило использование старого absolute layout при допустимом
смещении нижней таблицы. Воспроизведено9881/2 RED, исправлено9883/0 GREEN;
дополнительные config/metadata/guard проверки довели набор до9889/0. Вход теперь
принимает spec и вычисляет layout после проверки. Неразрешённых дефектов ревью нет.

Admin-публикация профиля, нормализация, полный rulebook, IP matching/cache Superset,
итоговый coordinator writer и XLAM ещё не завершены. **Рабочий выпуск2.0 не готов.**
