# Подготовка заявки к проверкам

Из подтверждённого снимка формы теперь создаётся контекст с типизированными
адресами и портами обеих таблиц, датой срока действия и признаком «бессрочно».
Номера строк, адреса ячеек и исходные значения сохраняются. Исходный файл
не открывается повторно и не меняется; результат доступен после его закрытия.

Дата обрабатывается по явно выбранному формату ISO или ДД.ММ.ГГГГ и системе
дат книги Excel. Строка с цифрами не принимается за числовую дату. Фиктивный
день 29.02.1900, дробные дни и даты вне диапазона отвергаются. Слово для
бессрочного срока задаётся явно; дополнительные синонимы не придумываются.

Неверный адрес или порт остаётся невалидным целиком: корректные части не
используются для положительного результата. Ошибки Excel сохраняются в полях,
чтобы последующий отчёт мог собрать все проблемы. Внутренний или конфигурационный
сбой отклоняет весь результат без выдачи частичных данных.

Протокол пока приводится к верхнему регистру ASCII и обрезается по краям.
Проверка допустимых протоколов, EMAIL/ENUM/HOSTNAME, правила отзыва доступа,
полный Rulebook и выдача понятных пользователю ошибок ещё не подключены.
Это подготовка данных, не готовая версия для повседневной работы.
