# Этап 2B.1 — IP и порты

Реализовано и проверено в настольном Excel 2026-10-16: Compile VBAProject PASS,

## Объём

Единая интервальная математика без разворачивания диапазона в отдельные адреса.
Нормализация объединяет перекрытия и смежные интервалы. Числа IPv4 до 4294967295
сохраняются точно; порты0..65535 соответствуют принятому kernel-контракту.

Поддержаны строгий IPv4, CIDR, полные/сокращённые диапазоны, compact lists,
x-маски по целому октету, многозначные поля и согласованные разделители портов.
Любой неверный token делает всё значение INVALID; превышение лимита — ERROR.
Маски с внутренним x ограничиваются бюджетом шагов и количеством интервалов.

Runtime выполняет domain ANY/NONE/OVERLAPS/COVER/CONTAINS/EXACT/IN,
INTERSECTS/CONTAINED_BY и equality. Числовые значения и LIST<NUMBER> преобразуются
в PORT_SET по сохранённому binding, включая функции и named defaults. Проверяется
каждое значение, в том числе дробное/выходящее за диапазон вычисленное значение.

Helper для будущего TOP↔LOWER отдельно сохраняет строгую декларацию CIDR: plain IP
отличается от /32, разные base IP одной сети не тождественны. Ordinary IP/ranges
сравниваются по фактическому покрытию. Domain payload заморожен, Scalar access закрыт.

## Проверки и ревью

- Исчерпывающий oracle: все4096 пары подмножеств0..5, отдельно overlap и coverage.
- IPv4 boundaries, /0,/32, разрывы, смежность, дубликаты, signed boundary2^31.
- Invalid tails, длинные/неполные октеты, compact/ranges, dashes, внутренние x и limits.
- Полное покрытие не подменяется пересечением. Сохранена логика short circuit.
- Native normalizer и numeric/function/list/default conversions подключены.
- Независимое ревью нашло пропущенную форму compact range continuation
  `192.0.2.1,3-5`: новый тест воспроизвёл1FAIL; исправление дало9563/0.
- Небольшой пробел тестов функций/списков/defaults закрыт четырьмя сценариями.
  Важных и малых замечаний без решения не осталось.

Ранние три ошибки ожиданий в тестах исправлены по нормативному направлению:
COVER означает A subset R, CONTAINS — R subset A; код не менялся ради неверных ожиданий.
Предыдущий negative fixture для неподдержанного IP заменён на ENUM, поскольку IP
теперь поддержан. Остальной scalar/compiler baseline сохранён.
