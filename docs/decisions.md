# Архитектурные решения

## ADR-001 — constructor-first, 19.10.2026
Решение: сначала универсальная схема, исполнитель и реальный Admin-конструктор, затем настройка NETWORK_ACCESS. Причина: отдельный проверочный движок и специализированные сетевые контроллеры старого пилота не доказали сквозную редактируемость. Статус: принято пользователем как направление; детали технического дизайна требуют утверждения.

## ADR-002 — сохраняем эталон AccessTools 1
Переписывать реализацию разрешено; менять существующее поведение без решения — запрещено. Требуется матрица проверки бизнес-семантики и реальных Excel-результатов.

## ADR-003 — сложные алгоритмы как Operations
VBA может содержать общую математическую/поисковую операцию; правила её применения, поля, источники, исключения и сообщения живут в данных.

## ADR-004 — владение Excel-результатом
Вычислитель не правит книгу. Единый Writer должен безопасно объединять аннотации, восстанавливать/сохранять пользовательское оформление и комментарии.

## ADR-005 — роли и публикация
ADMIN и Runtime разделены, FIRST_LINE и COORDINATOR получают опубликованные подходящие наборы правил; изолированные черновики, версии, откат.

## ADR-006 — архив старого пилота
Архив `archive/pilot-2026-10-18` с `6643f1c`; прежние 31 PR закрыты без merge, исходные ветки и история сохранены. В main только новая документация, никакого копирования устаревшего кода.

## ADR-007 — включительная семантика IPv4-диапазонов, 19.10.2026
**Утверждено владельцем и имеет приоритет над прежней трактовкой в ТЗ v0.13/v0.14.** Диапазон `10.0.0.1-10.0.0.10` представляет все десять адресов, включая промежуточные. Проверки Superset, разрешений/запретов, пересечений и полноты покрытия обязаны использовать весь интервал; сравнение только endpoints запрещено. Рекомендуется интервальная арифметика без перечисления адресов. `10.0.0.1,10.0.0.10` — два отдельных адреса, `10.0.0.0/24` — CIDR. Отдельные контракты: сравнение бизнес-деклараций TOP↔LOWER и сравнение математических IP-множеств, без неявной подмены семантики. Запланированная компактная запись `x.x.x.x,y` обсуждается отдельно. Регрессионные кейсы закреплены как AC-16. ТЗ v0.15: https://docs.google.com/document/d/1skCtOzRTq4_wuNNkZHSaeyWsh_sf_RjYq1OKDezmBKM/edit.
