# Чтение таблиц Excel: состояние

На 2026-10-16 добавлен общий читатель таблиц по внешнему описанию колонок.
Он находит единственный полный заголовок, учитывает объединения, пропускает
пустые строки и сохраняет физический номер строки и исходную ячейку каждого поля.
Данные передаются существующему ядру как неизменяемые строки с исходным TEXT.
Ошибки Excel остаются ошибками поля; испорченный IP не превращается в корректный
путём извлечения фрагмента. Исходные формулы, значения, объединения и оформление
читатель не изменяет. Нет кеша по имени книги и зависимости от старой надстройки.

Полный набор с компиляцией VBA в Excel: **9733 PASS / 0 FAIL**, отчёт
`artifacts/excel-ab3b8114e755480e8c9e6d33c9010241`. Проверены реальные временные
листы: merged заголовки, перестановка/дубли колонок, верхние и нижние пустые строки,
объединённое обоснование, ключи и вспомогательные поля, ошибка ячейки, пустая
формула, форматирование конца листа, границы и snapshot после закрытия источника.
Также проверено выполнение существующего DSL над извлечёнными строками.
Static tooling:7/7. Excel gate integration:9/9 (с разрешённым запуском Excel).
Чистая копия e23614e: компиляция и9733/0 повторены без прежних артефактов,
отчёт `artifacts/excel-f960b4c08d56499285469391d3fd9660`, static7/7.

Независимая проверка нашла два существенных случая с объединениями. Они
воспроизведены тестами (4 FAIL), исправлены и повторно проверены всем набором:
последний merge входит в границу чтения; merge нескольких разных колонок
отвергается, а merge внутри одного поля остаётся допустимым.

Layout действует в одном синхронном чтении; после изменения структуры листа
нужно повторить поиск. Это ещё не полный fingerprint шаблона. Пока описание
колонок передаётся программно, все значения исходные TEXT. Следующие шаги:
production-профиль NETWORK_ACCESS, одиночные поля, строгая сверка структуры,
нормализация и полный rulebook, Superset, координаторский результат и пакет XLAM.
