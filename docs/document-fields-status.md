# Одиночные поля формы: состояние

На 2026-10-16 добавлено чтение одиночных полей по внешнему описанию заголовка,
области поиска и смещения. Поддерживаются значения справа, слева, сверху, снизу,
а также точные смещения. Объединённые заголовки и значения учитываются по границам
и исходному якорю, а не по случайной внутренней ячейке.

Результат различает отсутствующий заголовок (MISSING), найденную пустую ячейку
(EMPTY) и ошибку Excel (ERROR). Непустой исходный текст сохраняется целиком.
Повторяющийся заголовок и выход за допустимые границы дают явную ошибку.
Снимок результата работает после закрытия источника, содержит только значения
и текстовые адреса; читатель не меняет исходные формулы, оформление или объединения.

Адрес одиночного поля передаётся в ATEvaluationContext и сохраняется в Snapshot
и trace вычисления. Внутри правил по строкам документное поле использует свой
адрес, поле строки — свой. Короткое замыкание и лимиты ядра сохранены.
