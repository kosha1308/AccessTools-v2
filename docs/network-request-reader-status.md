# Единое чтение заявки на связности

Этап собирает один неизменяемый снимок заявки: 11 одиночных полей и обе таблицы.
Сначала проверяется профиль шаблона, затем заново определяются границы таблиц.
При структурной ошибке частичные данные недоступны. Ошибка в ячейке данных
сохраняется для последующей проверки с адресом исходной ячейки.

Срок действия хранится как исходный текст и отдельно как числовое значение Excel,
если ячейка действительно числовая. Строка с цифрами числовой датой не считается.
Система дат книги Date1904 сохранена явно; преобразование дат — следующий этап.
Исходная книга не меняется; снимок работает после её закрытия.

## Проверка

- Реальный Excel: компиляция PASS, 9941 PASS / 0 FAIL.
- Проверены объединения, пустые строки, вставка строк, все 11 полей, C10 для
  учётной записи, адреса ячеек, числовой/текстовый срок, Date1904, ошибки ячеек,
  отказ шаблона до проверки параметров запуска, неизменяемость и выполнение DSL.
- Оригинальный XLSX открыт только для чтения: `OK|TECH=0|ADDR=0|DB='Лист1'!C10`.
  SHA256 до и после одинаков:
  `21684A4A985FD2057193B557E9D09C817C0899CE09DF7C697EF45025BC6714A7`.
- Отчёт: `artifacts/excel-a914b7b0fcb94b6fb4e9d5efd3e5495b` (локальный, не поставляется).
- Независимый обзор изменений до 021a145: замечаний нет.

Это чтение исходных данных. Нормализация, полный набор бизнес-проверок,
сопоставление Superset, координаторская сводка и пользовательский пакет ещё предстоят.
Новые поля СКУФ и команды поддержки из обновлённого ТЗ остаются обязательными.
