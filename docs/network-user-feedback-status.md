# Удобство проверки: источники, меню и примечания

Пилот 2.0.0-pilot.3 использует прежний AccessToolsv2.xlam и прежние 16 проверок.
Добавлен пользовательский слой; значения полей и семантика проверок не менялись.

## Источники

Первый выбор книги правил и Superset сохраняется между запусками Excel в
`%LOCALAPPDATA%\AccessToolsv2\sources.ini` (UTF-16, только два пути, без данных).
При отсутствии/повреждении настройки или удалении источника появляется выбор.
Кнопка «Выбрать источники» позволяет заменить оба файла. При недоступной записи
пути работают до закрытия Excel, ограничение явно сообщается. Настройка не входит
в manifest и не изменяет установленный пакет. Каждый запуск заново читает источники
через прежний контроллер: сохранение пути не означает использование старых данных.
Файл настройки заменяется через
[MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)
с временным файлом в той же папке. Тесты используют только свои временные папки.

## Меню и ошибки пользователя

После завершения появляется нативное всплывающее меню Excel: копирование всех
ошибок пользователя, отчёт, сводка, переход к заявке и сохранение результатов.
Кнопка «Результаты проверки» открывает меню повторно. В ленте теперь четыре кнопки.
Действия меню привязаны к фактическому имени этой надстройки, чтобы не обращаться
к первой версии. Новый/отменённый запуск сбрасывает старый результат меню.

Копируется только `InUserReport AND UserError AND ERROR`, с точными адресами ячеек.
Координаторские проблемы и WARNING не объявляются ошибками пользователя.
Текст не обрезается молча: превышение лимита 2 млн символов даёт явное ограничение
и предложение использовать отчёт. Буфер Unicode использует окно Excel как владельца
([OpenClipboard](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-openclipboard)).
Без клика пользователя автоматические тесты буфер не читают и не перезаписывают.

## Примечания в заявке

По явному запросу пользователя открытая заявка теперь получает обычные примечания
Excel в памяти, без изменения значений/формул и без автоматического сохранения.
В примечании выделен блок `[AccessToolsv2]...[/AccessToolsv2]` с идентификатором запуска.
Повторная проверка удаляет только свои блоки; чужой текст сохраняется. Объединённая
ячейка получает примечание в верхней левой ячейке. Ссылки на другие листы, диапазоны,
формулы и внешние книги не исполняются и не принимаются как цели.

Явная маршрутизация/подсветка Rulebook сохраняется. Если настройки для проблемы
нет вообще, ошибке заполнения пользователя по умолчанию ставится примечание.
Для этого добавлен признак наличия конфигурации у решения политики; статусы,
сообщения и значения существующих маршрутов не изменены. Согласования с явным
каналом заявки не превращаются в пользовательские ошибки для копирования.

Перед запуском удаляются старые собственные блоки, чтобы техническая ошибка
нового запуска не оставила их под видом новых. Защита листа, недоступная цель,
современный threaded comment или превышение размера не ломают рассчитанный отчёт:
показывается предупреждение. При превышении 32767 символов чужой текст не обрезается.
Неполные маркеры считаются чужим текстом и не переписываются. Чужое форматирование
примечания не гарантируется при объединении текста, значения и оформление ячеек
не меняются.

## Проверка

Тесты подтверждают сохранение/чтение Unicode-путей, отсутствие устаревшего состояния,
текст всех пользовательских ошибок, фильтрацию координаторских сообщений,
владение примечаниями, объединённые ячейки, явное запрещение примечаний, защиту,
длинный чужой текст, повторное обновление/очистку, видимое предупреждение при
неточной ссылке и структуру/адресацию меню. Свежий обзор кода выявил потерю счётчика
пропусков при очистке; исправлено RED21/1 -> GREEN22/0. Полный Excel regression
11330/0, compilePASS; новый popup не показывается при автоматическом тестировании.

В комплект добавлена «Заявка-с-ошибками.xlsx» с искусственными ошибками имени,
почты и действия. Прежний корректный пример оставлен. Отсутствие IP в Superset
само по себе не обязательно является пользовательской ошибкой или целью примечания.
Реальные клики меню, вставка из буфера и регистрация ленты требуют пользовательской
приёмки. Автоматической установки и изменения безопасности не выполняется.
