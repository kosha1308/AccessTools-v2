# Единый запуск NETWORK_ACCESS

Реализован `ATNetworkRunController.Run(requestSheet, rulebookPath, supersetPath,
runId, runDate, timezoneId)`. Он читает текущую заявку, заново загружает правила
и Superset, выполняет 16 проверок и формирует отдельные книги отчёта и сводки.
Готовые проверки не переписаны. Все адаптеры получают данные одного запуска.

`ATNetworkRunResult.IsComplete` означает завершение обработки; отдельный
`AllChecksPassed` требует PASS у всех 16 проверок. Успешное создание книг
не означает отсутствия замечаний в заявке.

## Источники и ошибки

- Несохранённая заявка допустима: читаются текущие значения без сохранения.
- Rulebook и Superset — локальные XLSX; открываются только для чтения,
  без обновления ссылок. Rulebook содержит семь именованных таблиц,
  Superset читается с первого листа.
- Уже открытый источник или книга с таким именем в текущем экземпляре Excel
  отклоняется. Пользовательская книга не сохраняется и не закрывается.
- Каждый запуск перечитывает и компилирует источники, без использования старого
  индекса. Путь, размер и время изменения проверяются до и после обработки.
  Это минимальная проверка актуальности, не криптографический контроль содержимого.
- Ошибка возвращает StateError, фазу и код; сводка не выдаётся. Созданные этим
  запуском выходные книги закрываются перед попыткой формирования отчёта об ошибке.
  Если вычисленный отчёт уже существует, он сохраняется в объекте результата.
- Восстанавливаются EnableEvents и AutomationSecurity. Настройки Trust Center
  не меняются. Закрываются только книги, открытые самим контроллером.

Формат ограничен XLSX, фактический формат книги также проверяется. ForceDisable
не отключает устаревшие Excel 4.0 макросы — см.
[документацию Microsoft](https://learn.microsoft.com/en-us/office/vba/api/excel.application.automationsecurity).
Поддержка произвольных форматов с макросами не заявляется.
Открытые источники в других экземплярах Excel и тождество через hardlink
не определяются. Файлы источников следует сохранить и закрыть перед запуском.

## Проверка

- Компиляция VBA PASS; полный набор Excel: 11286 PASS / 0 FAIL.
- Статические проверки инструментария: 7/0; проверка Excel gate: 9/0.
- Предоставленные шаблоны: 6/0, обе выходные книги созданы; SHA256 всех трёх
  исходных файлов до и после совпадает. Пустые шаблоны подтверждают структуру,
  но не заменяют приёмку с рабочими данными.
- Искусственные данные проверяют совпадения, оба слоя инструкций, замену файла
  между запусками, повреждённый заголовок, открытый несохранённый источник,
  защиту паролем, владение книгами и восстановление настроек после ошибки.
- Независимая проверка кода: блокирующих замечаний нет.
- Демонстрация единого запуска создаёт заявку, источники и две выходные книги;
  обе страницы PDF сводки просмотрены.
